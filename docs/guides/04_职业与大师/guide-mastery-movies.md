# 1.6大师技能与电影院（大肥鱼·AI执行版）

> 2026-10-30 | 来源: stardewvalleywiki.com/{Mastery, Movie_Theater} 实抓
> 定位: 1.6终局系统。触发前置=**五技能全10级**。

## 一、大师系统(Mastery, wiki实抓)

- **大师洞**: 森林桥(需要木桥修好, 300木)东北新入口。触发条件=五技能全10级 → 进洞见**大师雕像**。
- **大师点数(Mastery Points)**: 来自**经验条溢出**——10级后XP继续积累, **按溢出量的百分比折算**成点数(wiki实抓); 全树共需**6点**(4系各1+专属2?以游戏内树为准)。
- **选系**: 每点在雕像前**四系选一**(战斗/采集/钓鱼/耕种)——**按需要的顺序选, 不可逆!**

- **大师 XP 来源**: 一切技能经验10级后继续涨(钓鱼/种地/战斗/采集照常干), **不需要专门刷**, 玩到哪算哪。
- 溢出经验折算=百分比制(wiki实抓), 具体比率游戏内不显示——体感全技能10级后正常玩1-2季出满。

## 二、电影院(社区中心/Joja殊途同归)

- **建造**: 社区中心路线=JojaMart废墟重建(**500,000g**+材料, 罗宾或Morris对话触发); **Joja路线=社区中心变电影院**(买断10,000g后Joja项目)。
- 开业首周**免费票**。**场次: 12:00 / 15:00 / 19:00**(wiki实抓; 周末晚场以门口牌为准); 门口牌/馆内有当周片表。
- **每周两部片轮换**。

### 看电影收益(AI执行)

1. **请村民**: 票500g/张, 每场可请1人 → 邀请本身**+250好感**(wiki实抓; 非整心但每周两片多场次依然高效)。
2. **爆米花250g**; **带TA爱吃的零食**进厅=好感再加(每人口味不同, wiki Movie_Theater页有逐人表)。
3. **第一年村口老位置**: 电影后门口有随机村民聚聊。
4. 无好感工程压力时纯白玩(片单1.6固定池: It Howls in the Rain / The Brave Little Sapling / Wumbus 等)。

## 三、解锁顺序(与完美度清单衔接)

1. 五技能10级(见技能专精攻略) → 森林桥修好 → **进大师洞**。
2. 大师点优先级: **耕种(祝福雕像)>战斗(铁砧)>采集(神秘树)>钓鱼**。
3. 电影院500,000g: 排在**金钟(10,000,000g)与方尖碑之后**、豁免券方案之前——纯好感+娱乐, 不挡完美度(除非凑成就)。
4. 齐核桃室任务板(大家庭/饥饿挑战等)与大师线并行, 互不冲突。

## 四、纪律

1. **进大师洞第一件事**: 对wiki Mastery页拍四系树, 写进本文件后再点点数(不可逆)。
2. 祝福雕像=每天早上摸一下选buff(体力/速度/运气/战斗力?), **下洞日前=运气祝福**。
3. 电影院请客选片: 村民对片有口味偏好(分好坏评价), 请人前查wiki Movie_Theater的村民口味表。
4. 大师系统全程**零冲突**继续日常——别为刷大师点停掉印钞节奏。
