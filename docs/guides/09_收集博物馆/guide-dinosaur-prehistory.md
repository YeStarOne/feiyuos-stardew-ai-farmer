# 恐龙与史前线（大肥鱼·AI执行版）

> 2026-10-30 | 来源: Dinosaur_Egg页wiki实抓(概率已核); 其余=机制知识, 标"游戏内为准"处入游戏确认
> 定位: 图鉴/完美度支线+中期印钞小引擎。恐龙蛋黄酱800g/个, 恐龙蛋本身是博物馆献祭品。

## 一、恐龙蛋的全部来源(5条路)

1. **骷髅洞史前层打Pepper Rex(火龙怪)**: **~10%掉蛋**(wiki实抓) → **主渠道**。史前层7层以下随机出现(见骷髅洞攻略), 特征=蕨类植物+骨堆+火龙。
2. **钓鱼宝箱**: ~0.5-0.6%(wiki实抓), 顺带。
3. **挖掘场Bone Node骨矿点**: ~1.6-1.7%(wiki实抓)。
4. **远古斑点(蚯蚓)挖掘**: 姜岛挖点~0.6%, artifact trove ~1.1%(wiki实抓)。
5. **金蛋?否** — 别混淆, 金鸡是完美度奖励。

- **第一颗蛋的处理**: **博物馆先捐一颗**(图鉴+完美度), 之后每一颗都孵化。
- 博物馆只吃一颗: 孵化器(大鸡舍解锁)孵恐龙蛋出恐龙(孵化天数游戏内看进度条)。

## 二、恐龙养殖(大鸡舍线)

- 恐龙住**大鸡舍**, 产蛋周期**7天1颗**(游戏内观察为准) → 单只恐龙=每周800g蛋黄酱+滚雪球。
- 滚雪球: 第1颗捐博物馆, 第2颗孵, 成年→产蛋→蛋再孵; **目标=4-6只**(蛋源自持)。
- 恐龙蛋→蛋黄酱机=恐龙蛋黄酱**800g**(普通蛋黄酱190g的4倍)。
- 恐龙心情/抚摸同其他动物; 恐龙不下雨天不出门?鸡舍动物规则一致。
- 卖价: 恐龙蛋350g(基价, wiki口径)——直接卖不如转蛋黄酱(800g)。

## 三、史前文物与骨头(博物馆+挖掘场)

### 骨头系(1.5姜岛挖掘场)
- 挖掘场产: **骨碎片**(Bone Fragment)+**化石件**(蛇头骨/蛇椎骨/蛇尾骨/蝙蝠木乃伊/青蛙木乃伊/黑曜石剑柄?)。
- **岛田教授(蜗牛教授, 炸巨石救出)→岛西Field Office陈列柜**: 化石件**放对位置拼骨架**(蛇=头+N椎+尾), 拼对给金核桃+奖励(共5套骨架)。
- **骨磨机**(骨碎片→肥料类): Gunther特别订单奖励配方(做特别订单时确认)。
- (已删)骨碎片用途以骨磨机为主。

### 博物馆文物(史前相关)

- **文物来源汇总**: 远古斑点(锄挖)/钓鱼宝箱/怪物掉落/晶球(铁匠开, 概率文物)/**Artifact Trove(沙漠商人/齐售货机有换)**=文物集中来源。

## 四、AI执行纪律

1. **史前层=恐龙蛋+蕨菜+文物三合一**, 骷髅洞日遇到史前层清完怪再走(火龙掉蛋别错过)。
2. 挖掘场日(姜岛): 带锄+炸弹, 骨头+化石全收, 化石拼图在Field Office按提示放(位置提示在展柜)。
3. 博物馆献祭优先级: 恐龙蛋/古代种子>化石(岛Field Office)>普通文物>矿物(多余的晶球开卖)。
4. 恐龙蛋黄酱800g×每周7天×N只: 4只恐龙≈**4,570g/周**被动, 孵化后零边际成本。
