# AI玩星露谷·操坑实录（大肥鱼·AI执行版）

> 2026-10-31 | 来源: 小黑盒帖194989495(彧Z, 91赞)全文实抓——**同款技术栈SMAPI+NagiBridge+MCP的实战踩坑**
> 定位: day-loop/自动化脚本避坑清单, 全部是实测教训。

## 一、时间坑(最狠)

1. **一天≈现实14分钟**(6:00-2:00)。AI一次思考3-5秒=游戏内4-7分钟 → **长任务必须先pause_time**(NagiBridge有/pause /resume), 否则一天只够做几个动作。
2. **周三别去皮埃尔店**(我们日程表已有, 实测同款翻车: 12,000g背包升级白跑)。

## 二、交互坑

1. **NPC同格=永远对话不了**: interact只认面前一格 → 四步流程: `find_npc → 走到相邻格 → face → interact`。
2. **柜台挡交互**: 罗宾/克林特站柜台后, interact认的是柜台 → 绕到柜台正面; 还不行换别人(皮埃尔/走动NPC好说话)。
3. **同一NPC试3次没反应就放弃**——AI会死磕, 每次都是钱。

## 三、传送坑

- **warp不带坐标=随机落点**(实测落池塘里); 带坐标也可能卡货架后寻路出不来 → **只传验证过的格子, 宁可多走两步**。我们已知坑: warp('Mine')掉-99,-99 limbo, warp('UndergroundMine1')才是进矿唯一通路。

## 四、指令坑

- **/give用名字=造假物品**: 传"Wood"不报错但造出Error Item(占格子且回包ok:true!) → **必须用物品ID**, 且不同类别前缀不同(普通物/大型放置物/武器), 错一个字符=一堆废物。
- 物品放地上才有用: 箱子/小桶/洒水器在背包里是废物 → `use_held`摆出来。

## 五、清杂物坑

- **/clear_ground会连树一起删**(terrainFeatures含树)且**不掉收获**(不产木头/纤维) → 想拿材料别用它; 保树须自己排除格子。

## 六、AI行为经济学

- **清100个杂物≈¥1.2(100步)+上下文过长"忘了自己要干啥"** → 一次清5个正好; **重复劳动(刷材料)直接/give, AI只干有决策的事**。

## 七、收尾铁律

1. **收尾必须睡觉**——只有睡觉存档, 不睡当天全白干。
2. **背包满了先腾**——收获物掉地上。
3. 营业时间/NPC位置这类"游戏常识"AI照样踩 → 全部固化进日程表攻略(guide-npc-schedules.md)。

## 八、评论区补充(同栈玩家实测, 2026-10-31)

1. **失败设预算**: 同一入口**三次不过就换方案**——报错堆进历史会变成"这条路不通"的结论, 之后AI绕着走**看着像抗命其实是怕**; 允许它说"这条我搞不定"。
2. **动作返回一行制**: 别每步读全量状态(贵+漂), "做完一步只回报一行", 需要再问。
3. **常用动作录成固定命令**: 比每轮现想便宜得多。
4. **成本实测(彧Z)**: 优化后每天非高峰聊天+水群+2小时星露谷 **<¥4**; 之前总结踩坑就烧了¥8; dsh每次行动观察几分钱。
5. **day-loop必须强约束开局任务**(Jarma实测): 无约束的AI第一天跑去钓鱼/下矿, 不种地 → 我们的day-loop日程优先级设计是对的。
6. **参考项目**: github `amy2022525-sketch/stardew-agent-bridge`(联机+Docker开发中, 浅安QwQ)——NPC交互瓶颈的第二备选。
7. SMAPI版本升级会崩接口, MCP死循环要防(bailam)。
