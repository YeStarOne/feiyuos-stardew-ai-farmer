2. **沙漠首日**: 绿洲(Oasis)商店买星之果实/仙人掌种子; 沙龙(Sandy)解锁。
3. **骷髅钥匙**: 矿洞120层奖励 → 开骷髅洞大门(沙漠西北)。

5. **神秘齐任务线**(解锁赌场): 隧道锁箱放**电池包** → 火车站箱放**彩虹贝壳** → 镇长冰箱放**10甜菜**(绿洲有卖!) → 沙龙沙龙"沙龙龙嘴里放**太阳精华**" → 回农场木堆拿**俱乐部卡** → 赌场开了。

## 二、骷髅洞规则(wiki实抓)

- **无电梯**, 每次从1层重来; 每层必有一个回程梯子(起点处)。
- **20%梯子变竖井**: 一次跳3-8层(10%概率×2-1), 跳层扣血=3×层数(不会降到1以下)。同层多个竖井**掉落层数相同**, 随便挑。井不会跳过100层。
- **铱矿概率**: 随深度涨, **10→100层涨得最快** → 目标就是快速下到100层+, 别恋战浅层。
- **时间变慢25%**(1小时=54秒): 骷髅洞一天实际能挖更久, buff持续时间(游戏时长)同变长。
- **宝藏房**: 10层起随机, 公式=1%+日运/10+幸运buff/100。**100/200/300层保底宝箱**(1/2/3个)。
- **史前层**: 7层下~2.2%, 全清怪出梯子; 产恐龙蛋/蕨菜/古代种子, Pepper Rex(火龙)打完有奖励感。
- **怪兽要点**: 木乃伊=打倒后**炸弹补刀**否则复活(圣骑士附魔免复活); 蛇蛇掉虚空精华; 铱蝙蝠51+层, 高危。
- 晕倒=诊所1,000g+丢东西; 凌晨2点晕=1,000g或10%取低 → **带传送图腾保底**。

### 下洞打法(AI执行)

1. **食物**: 幸运buff优先——辣鳗(幸运+1速+1)/南瓜汤(幸运+2防+2)/魔法岩糖(全buff天花板, 齐 Gems换)。咖啡/姜汁汽水**可与食物叠加**。
2. **炸弹流**: 集群石头一枚炸弹搞定, 木乃伊也是它——去矮人处买(樱桃450/炸弹1000/大1600), 弹弓爆炸弹300g清理铱矿脉。
3. **楼梯流**: 结晶复制机复制**绿玉→周日沙漠商人1:1换楼梯**(999可叠一格)。齐的饥饿挑战允许用楼梯。
4. **技巧**: 直奔竖井不挖杂石; 到了100层再开宝箱+挖铱; 13:00前下到50层是及格线。

## 五、纪律(day-loop挂接)

1. **岛日程模板**: 上岛→快线到农场→浇水/收获→快线火山(10层+锻造)→下午钓鱼/核桃→回船。岛内时间照流, 17:00前必须出发回城睡觉(船6am开)。
2. **骷髅洞日模板**: 挑电视占卜高运日(见guide-luck-mechanics.md), 配南瓜汤+双幸运戒指→ 9:00进洞→楼梯流下100→宝箱+铱→17:00出来正好回城。每周至少留2天种田, 别连续下洞。
3. **预算红线**: 船票1000/天是固定成本 → 岛上日利润必须>3000g才划算, 否则先搞镇上经济。
4. **优先级**: 修岛农场(印钞机) > 火山桥+锻造(武器附魔) > 挖掘场(化石/教授) > 度假村(纯社交+Gus吧台)。
5. **齐 Gem优先换**: 魔法岩糖(下洞燃料) > 楼梯 > 铱蛇奶(如果没拿过) > 稀有种。
