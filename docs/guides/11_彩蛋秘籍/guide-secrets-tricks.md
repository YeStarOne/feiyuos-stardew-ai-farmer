## 二、刘易斯的紫色短裤(1.6全家桶彩蛋)

拿到市长短裤后(别急着交任务, 可玩出花):
1. 万民汤里放→州长和刘易斯专属反应
2. 集市展评格里放→被取消资格, **刘易斯塞750星币封口费**(白赚!)
3. 缝纫机+金锭=**镶边短裤**(可穿戴, 玛尼/刘易斯专属对话)
4. 钓竿**鱼钩槽**放短裤→专属浮漂样式, 且铱杆第二槽鱼钩不损耗(1.6!)
5. 刘易斯卧室放**楼梯**进秘密地下室→捡短裤会刷诅咒短裤怪(免疫攻击), 可重复刷多条
6. 姜岛交镶边短裤→刘易斯接下来28天在岛上**穿短裤当沙滩裤**(仅镶边版可行)

## 六、通用小技巧(非彩蛋但每天有用)

1. **运气是隐藏资源**: 看电视占卜"精灵们今天非常开心"=下洞/钓鱼/开神秘盒黄金日; 尽量把骷髅洞/淘金/开箱堆在幸运日。
2. **挂机钓鱼收杆**: 上钩瞬间屏幕抖动+音乐提示, 手机党震动设置打开。
3. **浇水壶升级日错开**: 铁匠升级当天没壶用→选雨天前一晚送修, 雨天不用浇。
4. **神秘盒子**=完美度100后锤石/钓鱼大量出; 齐Gem售货机换"好盒子咒语"提升品质。
5. 体力透支晕倒亏钱, **睡前吃一个能回体力的食物**比硬扛划算。
