## 一、核心机制

- 春15-17每天10am开(需巴士修好); Sandy店关, Oasis和沙漠商人照常。
- **卡利科蛋(Calico Egg)**: 节日货币, 是实体物品——**跨天保留, 但节日结束从背包和箱子里一起消失**, 卖出0g。→纪律: 17日结束前必须花光。
- ⭐**商人表是种子固定的, 且按"前一天入睡时间"变化**(脆音音+搜种器双重实证: 商人列表按入睡时村民位置扫描)。→ **AI纪律: 春14起每晚固定22:00入睡锁表; 不满意就重开前一天改入睡时间。**
- 建档前可用搜种器(desertFestivalCondition requireJas/requireLeah)选好种子: Jas卖魔法岩石糖, Leah卖100硬木(3蛋/个)。

## 二、刷蛋六通道(按AI性价比排序)

### 1. 骷髅洞炸矿(大头, 无需骷髅钥匙!)
- 蛋节点1-3蛋/挖; **任意石头**1-50%概率掉蛋(随深度升); 怪物2-50%/箱子最高33%掉蛋。
- **Egg Rating = 每5层+1 + 每激活Calico雕像+1**。雕像每层随机1个(含宝箱房), buff/debuff随机——摸到差buff(食物减半/木乃伊发怒/多怪物)可以直接重开当天, buff会变。
- **吉尔交分**(走之前必须交, 别晕倒): 55-999分=**500蛋+魔法岩石糖** / 25-54=200蛋+Gil帽 / 15-19=50蛋 / 20-24=100蛋 / 10-14=25蛋 / 5-9=10蛋 / 1-4=1蛋。⚠️**1000+分=作弊检测, 0奖励!**(分数控制在几百内)
- ⭐**Calico雕像效果随机**, 好的包括: 直接送10/25/50/100蛋、速度+1、回满血体力、怪伤-25%; 坏的包括: **蛋丢50%**、食物回复减半、多出怪物。坏效果重开当天可刷。
- 1.6.4起**普通矿洞不算分**, 只有骷髅洞炸矿和雕像有效。
- 马龙日常任务(每天3出2, 一日有效): 杀10怪=35蛋 / 下到30层=50蛋 / 12混晶或15铱=40蛋。
- 昏迷不丢金币不丢物品, 但背包蛋丢20%(醒来在Harvey医疗站, 10血)。

### 2. 赛马(白送100蛋)

- 5选手池每天出3个; 必须留在场内等比赛跑完。
- 可疑男(Oasis旁): 1蛋买"指定选手可能输"(操纵用, 低优先)。

### 6. 厨师(无限次, 免费满血满体力!)

- 组合(基料+配料): 主buff列=酱汁(+1速)/蘑菇奶油(+1矿)/樱桃糖浆(+1运)/辣蒜(+1攻)/浓郁马里纳拉(+1防); 基料=豆(+3防)/洞面包(+3矿)/稀有果(+3运)/超浓切达(+3攻)/虾(+3钓)。
- ⭐炸矿标准餐: 洞面包+辣酱=矿+3速+1(脆音音同款: 吃水果+辣酱)。
