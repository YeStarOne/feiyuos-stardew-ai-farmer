## 使用建议（少绕弯路）
1. **查状态一律 /state /status /surroundings /farm_report /machines /scan_chests**（全✅实测）
2. **过图一律 walk.cross**（CheatBridge v1.4）或 warp 主图
3. **买种/买物一律 /buy 远程**（warp SeedShop 后 /buy id 即可，不用站柜台）
4. **机器装取料一律 /interact**（/use 会报错）
5. **箱操作**：/chest 读 → /chest_take /chest_take_list 取 → /store 存（存后必复核）
6. **节日**：Beach 类 warp 直进；Town 类 walk.cross Town 从正门进
7. **吃/回血**：/eat /heal；**睡/结算**：/sleep /settlement_confirm（换日三件套）
8. 高级查询引擎 **/gsq?q=<GameStateQuery>**（如 PLAYER_HAS_MAIL Current ccBoilerRoom）可查任意游戏状态判定

## 历史坑速查
1. /use 锄地假 ok → 开垦用 BWF
2. 满箱 /store 静默 noop → 存后复核
3. 边界传送格 walk 不切图 → walk.cross
4. ReadyCheckDialog 点不动 → /key Enter 或 festival.auto
5. 机器装料=/interact 不是 /use
6. /animals 与 surroundings.animals 都看不到室内动物
7. state.inventory 在顶层
8. 节日场地坐标不能直接 warp（落 Temp 死区）；Town 类节用 walk.cross
