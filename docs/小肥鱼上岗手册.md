## 一、系统架构 (三桥 + 双mod)

| 通道 | 端口 | 用途 |
|---|---|---|
| NagiBridgeRemix | **7842** | 主控 HTTP: /state /warp /move /face /use /interact /select /craft /buy /heal /sleep /eat /menu /key /machines /surroundings /ladder /mine/elevator /screenshot |
| BehaviorBridge | **7845** | 行为学框选: GET /status /actions, POST /select{x1,y1,x2,y2,button} /clear /pause /resume |
| FeiyuAutoLoad 作弊桥 | **7846** | 自建作弊: GET /status, POST /give{id,count} /mine_tp{level} /onehit{on} /clock{minutes} |

- **FeiyuAutoLoad** (源码 `D:\StardewAI\FeiyuAutoLoad\`, 仓 `src/feiyu-autoload/`): 四自愈(自动读档/剧情补偿/弹窗自救) + 作弊服务。部署 = `dotnet build -c Release` → 杀 SMAPI → 拷 DLL 到 `G:\量化系统安装包\V1.6.15\Mods\FeiyuAutoLoad\` → 重启自动读档 → 轮询 /state worldReady。
- **启动/关闭游戏**: 启动=Start-Process StardewModdingAPI.exe (只许用户明说才做); 关闭前**必须 /sleep 存档**(见坑#1)。

## 二、开工/收工标准流程

**开工**: ①`curl :7842/state` 确认 worldReady → ②`node D:/StardewAI/mine-forever.mjs` (后台挂矿, 内置互锁自动杀旧进程) 或跑 day-loop.mjs 农活 → ③定期巡检 state+日志。
**收工**: ①停 node (killmine.ps1 按 CommandLine 杀) → ②warp FarmHouse → ③**POST /sleep** → ④等 `SaveGame.Save() completed` 日志 → ⑤才算完。

## 三、铁律 (违反=翻车, 按血案排序)

1. ⭐⭐⭐ **不 /sleep 就杀游戏 = 整日回滚**。11-03 实锤: 当天挖的 56 铁 40 煤全丢。
2. ⭐⭐⭐ **时间冻结时机器不走**: Furnace minutesLeft 永不减。产线烧条**必须走 /clock**, 一炉 120 游戏分。
3. ⭐⭐⭐ **NagiBridge /resume 后时间仍冻死** (paused=False 假象, 原因未明) — 别指望 resume 解冻, 直接 /clock。
4. ⭐⭐ `/machines` 只报**当前地图**; 人不在家查不到炉子。烧锭脚本先 warp FarmHouse。
5. ⭐⭐ `/interact` 不面朝目标无效 (actionTriggered:false)。投料/取锭/开机器前必须 face。
6. `/use` 只放可放置物 (箱/机器/种子/地板); 手持矿石对炉投料要 `/interact`; 手持工具对石才用 `/use`。
7. `/pause`/`/resume` 成对; **GET /pause 也会冻时间**, 只用 POST。
8. `/give` 背包满静默丢 → 先清垃圾; `addItemToInventory` 直接入包 (别用会弹 GrabMenu 的接口)。
9. 动作后必须重读 /state 校验; 每天必 /sleep; 新坑写进本手册+lib.mjs 注释。

## 四、主线流程 (科技第一生产力, 用户定调)

```
下矿(辅助) ─→ 矿石/煤/石英 ─→ 熔炉烧锭(/clock) ─→ 制造
     ↑                                ↓
  80+层金矿段 ←── 缺啥挖啥 ── 品质洒水器(1铁条+1金条+1精炼石英)
                                      ↓
                              自动化农场 → 春天高价值作物 → 钱源
```

- **烧锭**: `node craft-smelt.mjs [锭数] [Copper|Iron|Gold]` (动态发现炉位+4邻格走位+/clock 推进); 批量=`node smelt-session.mjs [铁条目标] [金条目标]`。
- **下矿**: mine-forever (eternal supervisor, TARGET 119, 互锁) → mine-session v0.7: /mine_tp 直达电梯最深层 → onehit 一击碎岩 → 清层找梯 → 无梯/死角**作弊下到层+1** → 重入矿 /pause 重锁时间。
- **合成**: POST /craft {name} (报 Missing materials 会列缺料)。
- **存档位规**: 现役 Day 2 冬 Y2; 铁条4/煤27/石英2/1470g; 洒水器 7 台已铺 (60,18)(71,18)(62,19)(69,19)(66,20)(60,21)(63,21)。
- **待办**: 金矿~40+石英 → 金条 → 品质洒水器 → 铺农场; 熔炉备料=20铜矿+25石头/台。

## 五、经济与政策 (用户拍板)

- 只卖 鱼+农作物+垃圾 (lib.isSellable 白名单); 其余存木箱/留背包; 采集物留 (收集包)。
- 体力用到 <15 才睡; 面包 (O)216 是口粮, /eat 自动吃; /heal 满血免费。
- /buy 任何物品 (桥模拟商店, 贵 3-10 倍); /give 白嫖 (用户已授权小额物资级)。
- 深夜 ≥21:00 或凌晨 → /sleep 存档到天亮, 别硬熬。

## 六、已知坑速查 (详见仓 docs/acceptance/)

| 症状 | 处置 |
|---|---|
| 渲染死冻/黑屏 | 唯一解: 杀 SMAPI 重启自动读档 (已有存档无损失) |
| 传送进图外/limbo (-99,-99) | 重 warp FarmHouse (9,9); 别 warp('Mine') |
| 梯子被石头围死 | mine-session 已自动清障+作弊下楼, 无需人工 |
| 同层死循环 (梯子概率掉落) | 换区 warp→30 格复扫→全空算清完→作弊下一层 |
| 时间漂移 2-3 游戏时/天 | /clock 累计正常现象, 不用修 |
| warp 被拒 (skipped_warp) | 该层未解锁电梯或落点不可站; 走 /mine_tp 绕过 |
| 角色卡死不动 | 查 /menu 有无弹窗 → Esc; 再不行重启读档 |
