## 1. 双实例与"桥"

两套游戏各带一个 **NagiBridge/Remix** 插件，暴露 HTTP 端点：

- 主持 `http://localhost:7842`、鱼鱼 `http://localhost:7843`
- 常用：`/state` `/warp` `/select` `/face` `/use` `/eat` `/sell` `/buy` `/fishbot` `/menu_close` `/settlement_confirm` `/screenshot` `/tile_props` `/passable_rect` `/warps` `/farm_report` `/mail` `/interact` `/gift` `/wakeup` `/pause` `/resume` `/heal`
- ⚠️ **必须用 localhost**，不要用局域网 IP。
- ⚠️ 杀进程按 **exe 路径/PID 精确杀**，绝不 `taskkill /IM Stardew Valley.exe`（会同时干掉用户正在玩的那个）。

### 端点铁律（血泪）
1. **`/fishbot` 不带 action = toggle**。查状态只能 `POST {"action":"status"}`；开 `{"action":"on"}`、关 `{"action":"off"}`。裸 GET / 空 body 会把开关翻一次（§54、§58）。
2. **所有 POST 带 `{}` body**，否则 Kestrel 返回 `411 Length Required`（`/menu_close`、`/settlement_confirm` 都踩过）。
3. `/eat` 吃的是"当前手持"：先 `/select {name}` 再 `/eat {}`（§60）。
4. `/sell` 只认 Farm 地图；中文名要用 node fetch 发（curl 在 Git Bash 会 GBK 乱码）。
5. `/sleep` 返回 ok ≠ 已写盘，唯一证据是 `SaveGameInfo` 的 mtime 前进。

## 3. 常驻守护（按启动顺序）

### 3.1 `fish-bridge.mjs`（:7850）留言板
- `POST /send {from,to,text}`、`GET /messages?to=名&since=id`（返回字段是 **`msgs`**）、`GET /status`。
- 落盘 `fish-bridge.json`，重启不丢。

### 3.2 `fish-eye.mjs`（:7851）人话助手
- `GET /say?cmd=看看|地图|该干嘛|水壶还有多少水`、`POST /say {text}`、`POST /goto {to:"海滩"}`、`/harvest /water /till /plant /refill`。
- 只读状态 + 批量动作；任何命令前会顺手 `/menu_close`，**不物理点击**。

### 3.3 `fish-concierge.mjs` 贴身管家
- 每 15s 读 `messages?to=肥鱼`，`from=小肥鱼` 的提问按关键词表秒回；无命中回"收到，主人巡检时回你"。
- 应答写入留言板 `to=小肥鱼`。

### 3.4 `newday-trigger.mjs`（:7861）换日总控 ★核心
- 每 20s 比 `year|season|day`，发现换日 → 清卡菜单（`ReadyCheckDialog` 关、`ShippingMenu` **点到消失**、`LevelUpMenu` **职业分支按偏好表 `/levelup_choose`**（无分支才关）、`SaveGameMenu` 等）→ 写 `newday-pending.json` → 留言板简报 → 经"定时任务通道"（`newday-bell.py`）把"新的一天"投进主持会话。
  - 专精偏好：farming `Tiller→Artisan` / fishing `Fisher→Angler` / foraging `Gatherer→Botanist(16)` / mining `Miner→Prospector` / combat `Fighter→Brute`（10 级取第二档）；选项不在列表里会退回强关并记日志。
- **卡死哨兵**：`timeOfDay` 4 分钟不动 + 有已知死锁菜单 → 两端救一次（5 分钟内不重复）。`time-lock.flag` 存在时整段豁免。
- 早晨赖床自动修：鱼鱼 `isInBed && 610≤t<1200`（最多试 3 次）→ `/wakeup`（只对 7843，主持禁用）。
- 调试：`GET :7861/status`、`POST :7861/force`（重放当天）。

### 3.5 `host-night-guard.mjs` 主持夜间守卫
- 23:30 或体力<20 → `/sleep`；睡后核对 `SaveGameInfo` mtime；"两人都在床但天数不前进"超 4 分钟 → `/cancel_sleep` + 破环。
- ⚠️ 它会在体力很低时提前把主持送睡 → 会触发全队 ready → **可能提前换日**（冬22 12:40 就结束过一天）。

### 3.6 `fish-night-guard.mjs` 鱼鱼夜间守卫
- `timeOfDay ≥ 21:30` 或 `体力 < 25` → 无条件 `/sleep`（曾被"听口令"坑到中暑晕倒）。

### 3.7 `day-activator.mjs` 每日激活
- 每 30s 看 7843 的 `dayOfMonth`，翻新就发一条今日简报给鱼鱼（日期/天气/运气/熟作物/任务清单），每天一次。

### 3.8 `fish-settlement-guard.mjs` 鱼鱼结算看门狗（2026-11-06 新增）
- 每 2s 读 7843，看到 `ShippingMenu` → `POST /settlement_confirm {}` 点到面板消失（8 次×1.5s 上限）。
- **只碰 7843、只认结算页**。解决"她卡在每日收入页 → 客户端加载推不动"（§59）。

### 3.9 `lock-fish-keep.mjs` 锁时双人钓鱼看护（2026-11-06 新增）
- 只在 `time-lock.flag` 存在时工作；flag 一删就自己退出。
- 每 20s 对 7842/7843：关挡路菜单 → 不在海滩传回去 → 竿不在手重选铱竿 → fishbot 用 status/on 校正；包快满（free≤2）回农场卖便宜鱼；**体力<90 自动进食到 220**（§60）。
- **假活 → 换钓点**：连续两轮硬重启（约 4 分钟）仍 0 鱼 → `/fish_areas` 取最近可站格 → warp → 面朝水 → 挂饵 → 重开（2026-11-06）。

### 3.10 `fish-fishbot.mjs` 鱼鱼自动钓鱼 keeper
- 30s 轮询：站 Beach(44,35) 朝东、5 分钟换一次竿（**优先铱竿**）、200s 补一次 ON、包快满回农场卖鱼。
- **停手条件**：`time-lock.flag` 出现（节日）→ 关 fishbot 退出；`t≥21:00` 或 体力<20 → 关 fishbot 等夜间守卫。
- 启动：`powershell Start-Process cmd '/c node D:\StardewAI\fish-fishbot.mjs >> ...\fish-fishbot.console.log 2>&1'`。

## 4. 主持全自动日循环 `day-loop.mjs` ★

一次运行最多连玩 3 天；`+++` 有锁文件 + 进程级查重（`get-dayloop-pids.ps1`），防止双实例抢角色。

**单日流程**：出床(warp Farm 64,15) → 找木箱 → 满包清仓 → 收菜/补种 → 查信 → 浇水 → 清死株 → 扩田 → 攒木做箱（`chopWood(50,40)`）→ 海滩钓鱼(fishbot) → 23:00 或体力<15 收工 → 白名单卖货 → 回家 `/sleep` → 核对存档 mtime。

**钓鱼循环里的三道保险**（都是 2026-11-06 加的）：
1. 每 200s 心跳：**手里没竿就重选**（宝箱/换饵会把 currentItem 打空，fishbot 报 enabled=true 也不抛，§57）。
2. **停滞哨兵**：10 次心跳 fishCaught 与体力都没动 → fishbot 硬重启（off→on）+ 重选竿。
3. **跨天退出**：`dayOfMonth !== day` 立刻退出钓鱼段（防空转一整天）。
4. 弹菜单处置：`ItemGrabMenu` 先点 (265,160) 捡宝箱，再双 `menu_close`。

**启动 / 停止**
```bat
:: 启动（后台，日志追加）
powershell -NoProfile -Command "Start-Process cmd.exe -ArgumentList '/c node D:\StardewAI\day-loop.mjs >> D:\StardewAI\day-loop-live.log 2>&1' -WorkingDirectory D:\StardewAI -WindowStyle Hidden"
:: 停止（按 PID；Git Bash 里 taskkill /PID 会被转义，要用 PowerShell）
powershell -NoProfile -Command "Stop-Process -Id <PID> -Force"
rm -f D:/StardewAI/.day-loop.lock
```
⚠️ 改 `lib.mjs` / `day-loop.mjs` 后**必须重启进程**才生效（常驻 node 缓存模块）。

## 7. 运维速查

### 全量重启顺序（游戏已在跑）
1. `fish-bridge.mjs` → 2. `fish-eye.mjs` → 3. `fish-concierge.mjs` → 4. `newday-trigger.mjs` → 5. `host-night-guard.mjs` + `fish-night-guard.mjs` → 6. `day-activator.mjs` → 7. `fish-settlement-guard.mjs` → 8. `fish-fishbot.mjs`（要她钓）→ 9. `day-loop.mjs`

### 常见故障对照
| 症状 | 先查 | 处置 |
|---|---|---|
| 鱼在钓但 `fishCaught` 不动 | `player.currentItem` 是否为空、`rod.inHand` | `/select 铱竿` → `/face 1` → fishbot on（§57） |
| 抛不出竿、`bobberX=null` | `activeMenu` 是否 `GameMenu` | `POST /menu_close {}`（§57 附注） |
| 换日卡住不动 | 两端 `activeMenu` | 先各发 `menu_close`；鱼鱼包满弹 `ItemGrabMenu` → 杀掉 fish 客户端 → 主持存档 → `restart-fish.ps1` |
| 结算页卡着她 | 7843 `activeMenu=ShippingMenu` | 已由 `fish-settlement-guard.mjs` 自动点（§59） |
| 鱼鱼在床上不动 | `isInBed && t≥610` | 只对 7843 `POST /wakeup`（主持严禁） |
| 时间不走 | `time-lock.flag` 在不在 | 在=正常锁时；不在=卡死哨兵处理 |
| 背包满 | `inventory.length / maxItems` | 卖白名单 / 存木箱（66,16 附近）/ 不吃种子面包 |
| day-loop 日志空白 | `.day-loop.lock` mtime 有没有在跳 | 有跳=正常（只在背包变化时打日志）；没跳=重启 |

## 9. 铁律（每轮巡检都念一遍）

1. 每天 `/sleep` 存档，且只认 `SaveGameInfo` mtime。
2. 每个动作后重读 `/state` 校验。
3. `/use` 只认面朝格。
4. 水壶空了先 `/refill`。
5. `/pause` 与 `/resume` 成对。
6. 新坑写进方案文档 + 代码注释。
7. 游戏连不上**绝不 Start-Process 拉起**（只有用户明确说"启动"才拉）。
8. farmhand 端必须走 `start-fish.bat`，否则单机读档会造成双世界互相覆盖。
