## 13. 参数与调用陷阱（血泪版）

1. **中文必须走 node fetch**：Git Bash 的 curl 发中文会被转成 GBK，`/hud`、`/chat`、`/sell` 全变乱码。实测 curl 发「时间已锁定」→ 回包 `\u02B1\uFFFD...`；node fetch 同样内容回包完全正确。
2. **POST 必须带 `{}` body**：`/menu_close`、`/settlement_confirm`、`/refill` 空 body 会 411。
3. **`/fishbot` 不传 action = toggle**（§54/§58）。
4. **`/eat` 吃手上**：先 `/select` 再 `/eat {}`（§60）。
5. **`/give` 只认限定 ID**：`(O)388` 木头、`(O)131` 沙丁鱼；写名字会造出 Error Item。
6. **`/surroundings` 4096 格上限**会直接报错，不会静默截断。
7. **`/tile_props`、`/dump_tile` 用 query 参数**，不是 JSON body。
8. **`/passable_rect` 一次 96×96**，大图要分块。
9. **`/warp` 是"下一 tick 落地"**，发完必须轮询 `location` 确认，别马上开钓（会在田里抛竿）。
10. **`/focus` 会抢用户焦点**，前台互锁（`fg-name.ps1`）之外再加一条：用户可能在用电脑时别调。
11. **`/click` 系端点要游戏前台**（物理鼠标语义），自动流程优先用 `/menu/click`、`/tool_area` 这类无点击端点。
12. **`/queue` 的 body 是数组**，不是对象。
