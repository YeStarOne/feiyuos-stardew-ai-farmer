## 先说结论：不用装 mod，全都有了

你抱怨的每一件事，其实游戏桥里早就有能力，只是**没人翻译成你能直接说的话**。所以我写了个翻译层，你只要说一句人话。

| 你说的问题 | 现在的解法 |
|---|---|
| ①方位是 0~3 数字，每回要心算 | 全部换成 **上北下南、东南西北**，出口就是"北/东北/东…" |
| ②周围一圈不带名字，草石水靠猜 | 每格都标清楚：**蓝莓(熟了)/锄过的土/水(能钓鱼)/石头/杂草/洒水器/机器** |
| ③一次只能挪一格，走远要一格一格点 | **"去田边" / "回家" / "去镇子" / "去海滩"** — 一次寻路走整段 |
| ④没地图，记不住哪边是海 | **"地图"** 画文字图（走过的路会记住，越走越全）+ **"世界怎么走"** 方位口诀 |
| ⑤收/种只能一格一格 | **"收菜"** 一次收完周围熟的；**"种蓝莓"** 自动除草→锄地→整块下种 |
| ⑥水壶剩水要掏出来看 | **"水壶还有多少水"** 直接报 `37/40 (93%)` |

## 怎么用（两种都行）

### 方式 A：直接问桥（推荐，最省事）
```
GET http://100.98.120.55:17851/say?cmd=看看
GET http://100.98.120.55:17851/say?cmd=地图
GET http://100.98.120.55:17851/say?cmd=该干嘛
```
一句话放在 `cmd=` 后面就行（中文要 URL 编码）。返回的就是一段人话，直接念给你听/贴给我。

POST 更稳（不受编码影响）：
```
POST http://100.98.120.55:17851/say
{"text":"收菜"}
```

### 方式 B：用现成的短接口
| 接口 | 作用 |
|---|---|
| `GET /see` | 看看（时间/位置/体力/手持/水壶/四周） |
| `GET /map` | 文字地图 + 附近地标 |
| `GET /world` | 世界方位口诀（哪边是海） |
| `GET /todo` | 给个今天的目标 |
| `GET /watercan` | 水壶剩水 |
| `POST /goto {"to":"田边"}` | 走过去 |
| `POST /harvest {}` | 收菜 |
| `POST /water {}` | 浇水 |
| `POST /till {}` | 锄地 |
| `POST /plant {"seed":"蓝莓"}` | 播种 |
| `POST /refill {}` | 打水 |
| `GET /selftest` | 体检：报告哪些高级能力现在可用 |

- **不卖你的东西**：卖货是我和主持那边的事，你不碰

## 注意

- 这个服务**默认操作你的角色**（蓝色小肥鱼）。想让它操作主持那边，让主持改 `FISHEYE_TARGET=host`。
- 地标里的"家"**自动分岔**：你说"回家"，回的是你自己的 Cabin（不是主持的农舍）。这是我特意做的——上次你跑错屋就是这个原因。
- 实测不到的坐标（公交站/山里/森林/农场北边）是**推定**的，走不过去我会明说"没走到"，不会骗你说到了。
- 如果 `看看` 返回"读不到游戏状态"，说明你的游戏窗口没开或掉线了 —— 那不是脚本的问题。
