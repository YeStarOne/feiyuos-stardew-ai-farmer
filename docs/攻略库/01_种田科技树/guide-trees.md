# 树木全图鉴（大肥鱼·AI执行版）

> 2026-10-31 | 来源: 小黑盒帖132711608(鬼道幽狐, 334赞)全文实抓
> 定位: 果树/普通树/树肥一览, 服务温室布局与工匠链原料。

## 一、果树(8种)

- **28天成熟**, 结果季每天1果, **未收可累积3天**; 不用浇水, 幼苗任何季节可种; **生长期周围必须清空**(受阻次日提示)。
- ⭐**可种温室/姜岛**: 全年结果且不变色。
- ⭐**砍成熟果树=掉同品质树苗**; 品质越高重种成熟越快 → 好苗可"复制"。
- 果实品质**逐年升, 上限铱**。
- 品种: 春=杏/樱桃; 夏=橙/桃/芒果/香蕉; 秋=石榴/苹果。
- 香蕉/芒果树: 姜岛购买或开金色椰子/老虎史莱姆掉/岛屿办事处奖励。
- 普通树苗: 皮埃尔/猪车/骷髅洞宝箱层。

## 二、普通树(挂采集器收益表)

| 树 | 采集器周期 | 备注 |
|---|---|---|
| 枫树 | 9天=枫糖浆 | 秋末两周摇树掉榛子; 蜂房配方原料 |
| **橡树** | **7天=橡树树脂** | ⭐**小桶+高级生长激素原料=印钞上游**, 需要量最大 |
| 松树 | 5天=松焦油 | — |
| **桃花心木** | **每天=树液** | 砍=8-13硬木; 种子来源=大树桩/大原木/秘密森林史莱姆/金色椰子 |
| 蘑菇树 | 采集器=红蘑菇 | 秋天5%/天普通树自然变; 核桃房买种; 砍=1%蘑菇帽; 冬落桩春再生 |
| 苔雨树(3种) | 种类3每2天=蕨菜 | 苔雨天75%树会变; 加速周围树长苔藓 |
| 棕榈 | 不能挂采集器 | 沙漠/姜岛; 摇/砍掉椰子, 姜岛=金色椰子 |
| 神秘树 | 7天=神秘糖浆 | 采集精通解锁配方; 不散播; 浣熊妻子交易需要 |

- 树苗周围3×3有成熟树→卡在第四阶段(规划间距)。
- 苔藓: 除冬季外长在枫/橡/松/苔雨树上(蘑菇流原料)。

## 三、树肥

- 只加速**野树**(果树/茶树无效); 每晚跳1阶段到第4阶段, 2天后成树; **冬天也能长**。
- 桃花心木60%/晚, 神秘树30%/晚(概率打折)。
- ⭐AI执行: 硬木线(桃花心木)+橡树树脂线开局就铺; 温室四角摆果树(8种各一=果实图鉴+礼物源)。
