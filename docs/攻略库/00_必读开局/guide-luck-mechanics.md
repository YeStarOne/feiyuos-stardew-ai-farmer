# 运气机制全解（大肥鱼·AI执行版）

> 2026-10-31 | 来源: 小黑盒帖126793618(滑只因, 573赞)全文实抓, 机制与wiki一致
> 定位: 运气是隐藏资源, 本文把它变成可计算的日程参数。

## 一、运气分层(wiki同口径)

| 层 | 范围 | 特性 |
|---|---|---|
| **每日运气** | -0.1 ~ +0.1 | 前一天活动决定, **读档不改**(SL改运无效); 电视占卜可看 |
| **特殊魅力** | 永久+0.025 | **计入每日运气**; 获取见下 |
| **幸运戒指** | +1/个, **可叠2个** | 单独计算, 不入每日运气 |
| **食物增益** | +1~+4 | 单独计算, 与戒指叠加 |

- **换算**: 每日+0.1=事件概率+10%; 增益+1=概率+1%(=每日运气的0.01)。
- 原生游戏运气等级恒0级, 增益次日清空。

## 四、运气影响清单(按我们日程排序)

**下洞日(高运日必排)**: 楼梯生成率/煤炭·晶洞发现率/宝石矿与神秘矿石/矿井箱子/**骷髅洞宝藏房**/死亡掉钱减少/放射性矿石(挑战期间)。
**钓鱼日**: 钓鱼宝箱出现率/宝箱内谜之盒与稀有物(海王星大剑/五彩/铱环)/**海之宝石后鱼籽数量**(宝箱出鱼籽本身恒25%)/木跃鱼(森林农场)。
**农场日**: **收获额外作物概率**(任何作物, 触发有特殊音效)/鸭毛兔脚掉率⚠️**不受运加影响**(!)/树上掉木材数。
**杂项**: 淘盘品质与数量/垃圾桶出货率/蝴蝶祝福出五彩/金色动物饼干(耕种精通)/赌场老虎机/雷雨闪电数(高运=闪电多, 装避雷针!)。
**不受运气影响**: **晶球内容物**(稀有宝石/古物只看晶球种类与顺序, SL晶球无用)/兔腿鸭毛掉率/钓鱼宝箱内稀有率(只影响宝箱生成)。
