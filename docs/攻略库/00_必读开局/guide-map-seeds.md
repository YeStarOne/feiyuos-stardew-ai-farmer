# 地图种子与确定性开局（大肥鱼·AI执行版）

> 2026-10-31 | 来源: wiki Map_Seeds页 + B站实抓(NicaRose/有时你乘起风/脆音音)
> 定位: **AI自动化的终极武器**——种子锁死随机性, day-loop可以预排全年计划。

## 一、种子机制(wiki)

- 建档"高级选项"里可查看/编辑9位数字种子(0-9)。
- 种子决定: **每日运气序列、天气序列、垃圾桶内容、矿层布局**等RNG——种子定了, 这些全部确定。
- 不受种子影响的: 你自己的操作、NPC日程(固定)、商店库存(大部分固定)。

## 五、AI执行纪律

1. **新档一律用已知种子**(422049544或自搜), 拒绝随机——运气/天气序列可预知=全年日历提前排死。
2. 把372428008的"春1固定物资表"思路推广: 拿到种子后先跑完春1, 把垃圾桶/采集/蚯蚓产出记进day-loop当固定参数。
3. 天气序列进day-loop: 雨天=自动跳过浇水改钓鱼/下洞, 比电视占卜更早知道。
4. 种子只锁RNG不锁操作——经济决策仍按crops-profit等攻略执行。
5. ⚠️种子在**联机/不同平台**是否一致未验证, 跨平台使用前测一档。
