# 开局前8天清单+第一年骨架（大肥鱼·AI执行版）

> 定位: 春1-8逐日SOP。原则照旧: 每种鱼留第一条(献祭)/每样古物先捐博物馆。

## 一、逐日清单(春1-8)

**Day1**: 屋内三连(炉火→包裹→电视)→锄15格种防风草浇水→50木做宝箱存杂物。
**Day2**: 看电视+浇水→威利信→海滩领鱼竿; 路上刨蚯蚓/买3防风草种/见人打招呼; 试钓鱼, **每种鱼第一条留存**(献祭)。
**Day3**: 种昨日买种+浇水; 采集: 黄水仙留1株(其余送礼), 野山葵/韭葱/蒲公英各留1株(包用)。
**Day4**: 古物送博物馆(**捐5古物=9花椰菜种子**)→领日志奖金→砍树冲采集1级(解锁种子掉落+2配方)。
**Day5**: 收15防风草(**金星留献祭**, 普通留1余卖)→矿洞开放(滑坡清了)→50木做稻草人→**猪车首日**(周五/日, 森林)→耕种1级解锁稻草人配方。
**Day6**: 买5花椰菜种+余钱全买土豆种(**趁雨种免浇水**)→乔迪家门口河钓鲶鱼冲"渔夫"成就→矿洞拿生锈剑+铜矿/石/煤→22:30前回家摆稻草人。
**Day7-8**: 熔炉配方/帽子商店解锁→社区中心流程(村长事件→左下亮块激活祝尼语→法师→工艺室)→**集齐春采集包一次性献祭**→开晶球新矿物捐博物馆。

## 二、开局私货技巧(3652赞帖独有)

1. **兑奖券白拿法**: 拿家里的**椅子**放超市上方围栏处→镰刀割草开路→**坐椅子跳进去**拿兑奖券→镇长家兑奖机抽**胡萝卜种子**。
2. **宠物猫碗里浇水**(春12收养)→额外好感。
3. **夏天洞窟选蝙蝠**——洞窟产水果=献祭+果酒双用(蘑菇线靠采集等级补)。
4. **啤酒花布局**: 洒水器横向隔3格、斜向下铺, 中间留过道; 收的啤酒花全进小桶(3×价), **多余的存箱秋冬照酿**(啤酒花不腐)。
5. 橡树树脂→小桶链: 春天就挂树液采集器, 别等夏天。
6. 收集包判定: 献祭开启后**鼠标指物品图标闪烁=收集包需要它**。
7. 电视节目价值: 离地而居(新手贴士)/酱料女皇(菜谱)/占卜(运气, 见运气攻略)。
