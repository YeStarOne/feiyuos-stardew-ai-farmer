## 二、工匠品机器优先级(什么先造)

| 机器 | 解锁 | 用途 | 周转 | 优先级 |
|---|---|---|---|---|
| **腌菜罐** | 农耕4 | 蔬菜→腌菜(2倍价+50g, wiki公式; 小桶果汁=2.25倍) | 2天 | ⭐⭐⭐量大管饱 |
| **奶酪机** | 农耕6 | 牛奶→奶酪 | 3h?200min | ⭐⭐⭐ |
| **蛋黄酱机** | 农耕2 | 蛋→蛋黄酱 | 3h | ⭐⭐⭐(养鸡就造) |
| **压酪机** | 农耕6 | 羊奶→山羊奶酪 | 200min | ⭐⭐ |
| **酿酒桶** | 农耕8 | 水果→酒(3倍价) | 7天 | ⭐⭐⭐终局(星果酒2,250g+Artisan=3,150g) |
| **蜂房** | 农耕3 | 蜂蜜(100g+花加成) | 4天 | ⭐⭐(童话玫瑰蜂蜜680g) |
| **织布机** | 农耕7 | 羊毛→布料 | 4h | ⭐⭐ |
| **油机** | 农耕8 | 松露→松露油 | 6h? | ⭐⭐⭐(猪场配套) |
| **结晶复制机** | 采矿9 | 宝石复制 | 与宝石价有关 | ⭐⭐(钻石/翡翠印钞) |

- **Artisan专精(+40%)是整个加工线的乘区**, 技能专精攻略里已定。
- **转化公式**: 腌菜/果酱 = 2×原料价+50g; 小桶酒(水果) = 3×原料价; 小桶果汁(蔬菜) = 2.25×原料价 → **水果进小桶, 蔬菜进腌菜罐**(腌菜罐反而比果汁高)。
- **鱼塘流补充(社区帖)**: 鲟鱼入鱼塘产籽→罐头瓶4天=鱼子酱500g, 夏冬矿湖钓鲟鱼自循环, 四季都有收入。
- **熏鱼机注意**: 熏鱼=2倍价但要1煤/条(煤150g), 低价鱼熏了亏本 → 只熏高价鱼。→ **便宜果酿酒、贵果卖鲜**不成立——全转酒(时间换钱), 腌菜罐接一切蔬菜。
- 产能规划: 腌菜罐数量=蔬菜日产量×2天; 酒桶=星果收获量×7天(温室星果55g/天/格→**酒桶是瓶子瓶颈, 有多少造多少**)。

### 洒水器量化方案(社区实测)
普通24个=95格啤酒花 / 40个=160格作物 / 优质16个=144格 / **铱8个+祝尼魔小屋=192格**; 蘑菇树桩54个、小桶满摆137个。规划地块先按此配机器数量。
**祝尼魔小屋+葡萄干**(秘密纸条#26): 消耗1葡萄干=当日收获20%双倍 → 自动化产量乘区, 姜岛毕业后标配。

## 三、经济链全景(第二年日利润模型)

1. **温室+岛农场星果/杨梅 → 全部酿酒** (时间长的进酒桶)
2. **岛农场地格种星果, 收获进酒桶, 酒卖店** — 岛农场876格满配星果酒≈**876×25g?** 实际: 星果日收益25g/格种鲜果, 酿酒后终值≈75g/格/天(含7天周转)。
3. **猪群松露→松露油** + 奶牛奶酪 + 鸡蛋黄酱 = 每天稳定3-6k
4. **铱洒水器+农业** 只保留收集包/礼物/食谱需要的地块, 其余全上动物和机器
5. 矿洞日+钓鱼日穿插补充(见对应攻略)

## 四、AI执行纪律

1. 建筑下单找罗宾: **Coop(4,000g) → 大Coop(10,000g, 孵化器/鸭/兔) → 豪华Coop(20,000g, 自动喂食) → Barn(6,000g) → 大Barn(12,000g, 羊/怀孕) → 豪华Barn(25,000g, 猪/自动喂食) → 自动采集器(25,000g)**; 细分材料表见guide-animals.md, 两份互补。
2. 动物购买顺序: 鸡×4 → 牛×2 → 鸭→山羊→猪(钱到位就上猪, 松露油线)。
3. **每天流程**: 抚摸(自动抚摸器到位后跳过)→开门→检查自动喂食→出门办事→傍晚关门。下雨天动物不出门但照喂。
4. 收集包联动: 动物包(大蛋/奶/羊毛任6)、工匠包(奶酪/山羊奶酪/布料/蜂蜜)在满配前**留货**别全卖。
5. 罗宾好感(秋21生日+意面)提前喂到4心, 建筑排队不折腾。
